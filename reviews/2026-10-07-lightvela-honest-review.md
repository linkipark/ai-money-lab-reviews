## The flaw

LightVela's cloud browser has no persistence — effectively incognito mode every session. Log into a site, finish the task, come back later: you're logged out, starting from zero. For a product pitched as "a personal agent that remembers you," this breaks the core promise and makes logged-in web automation painful or impossible.

## Smaller gripes

- The international version still has sensitive-word filtering.
- The model picker is thin — mostly "auto," no way to pin a specific model per agent.

## Verdict

LightVela is the lowest-friction path from "I want an AI agent" to "my agent just pinged me on Telegram." Genuinely useful today for chat-based recurring tasks (reminders, briefings, monitoring). But until browser persistence lands, it's a brilliant demo, not a daily driver.

- If you live in Telegram or Discord and want an always-on assistant for chat tasks: try it.
- If you need logged-in web work done for you: wait.
